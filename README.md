# Professor Gabriel Games — Unity 2D

Prévia web em React + TypeScript + Remotion da Aula 1, com personagens e cinco painéis simulados. A voz e o MP4 final ainda não foram gerados.

## Executar

```bash
npm install
npm run dev
```

## Render

Criar **Static Site**, conectar este repositório (branch `main`), usar build `npm install && npm run build` e publish directory `dist`.

Os painéis são uma simulação educativa, não o software Unity oficial.
